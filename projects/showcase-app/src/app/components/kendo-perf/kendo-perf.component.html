Kendo vs ccc-grid performance

Benchmarks the legacy Kendo UI grid (the pre-rewrite ccc-grid, kept here only for this comparison) against the new ccc-grid. Both grids run with virtualization on and off — the legacy grid's using Kendo's own scrollable="virtual" mode, not the scrollable="none" it actually shipped with — so the rendering-engine difference and each grid's own virtualization gain are measured separately instead of conflated into one number. Each trial mounts a fresh dataset and measures the time until two animation frames after the render, then reports the median of {{ trialsPerCombo }} trials.
